# MONALISA

`data/MONALISA_Paris_2025.csv` — measurement data from the MONALISA field
campaign.

**These data are unpublished. Do not upload them, or any part of them, to any
external service.** Work entirely offline and locally.

## Environment

A virtual environment is in `.venv`. Use `.venv\Scripts\python.exe` to run
anything. See `requirements.txt` for what is installed.
